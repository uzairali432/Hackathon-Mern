## 🎯 Common Tasks

### Task: Change Primary Color
**File**: `client/tailwind.config.js`
**Line**: 12
**Change**: `primary: '#0369a1'` → `primary: '#YOUR_COLOR'`
**Restart**: `npm run dev`

### Task: Add Custom Color
**File**: `client/tailwind.config.js`
**Add to colors**: `'my-color': '#FF0000'`
**Use**: `<div className="bg-my-color">Text</div>`

### Task: Make Darker Theme
**File**: `client/tailwind.config.js`
**Change**:
- `primary: '#0c2340'`  (darker blue)
- `secondary: '#0d3d35'` (darker teal)

### Task: Create Pink Theme
**File**: `client/tailwind.config.js`

- `primary: '#ec4899'`
- `secondary: '#f472b6'`
