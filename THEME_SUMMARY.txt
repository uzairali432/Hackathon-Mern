WHERE ARE THEME & COLORS DEFINED?

There are 3 main locations where your theme is configured:

1. PRIMARY SOURCE - Tailwind Configuration
   📁 File: client/tailwind.config.js
   📝 What: Color definitions, border radius, shadows
   🎨 Main Colors:
      • Medical Blue: #0369a1 (primary buttons, headers)
      • Medical Teal: #0d9488 (secondary buttons, wellness)
      • Cyan Accent: #06b6d4 (highlights, interactive)
      • Success Green: #059669 (success states)
      • Error Red: #dc2626 (errors)
      • Warning Orange: #f97316 (warnings)

2. BACKUP SOURCE - CSS Variables
   📁 File: client/src/styles/index.css
   📝 What: CSS custom properties, typography, animations
   🎨 Variables:
      :root {
        --medical-primary: #0369a1;
        --medical-secondary: #0d9488;
        --medical-accent: #06b6d4;
        --health-accent: #10b981;
        --medical-dark: #0c2340;
        --medical-light: #e0f2fe;
        --chart-primary: #0284c7;
        --chart-secondary: #0891b2;
      }

3. USAGE - All Component Pages
   📁 Files: 
      • client/src/pages/LoginPage.jsx
      • client/src/pages/SignupPage.jsx
      • client/src/pages/PatientDashboard.jsx
      • client/src/pages/DoctorDashboard.jsx
      • client/src/pages/ReceptionistDashboard.jsx
      • client/src/pages/ProfilePage.jsx
   📝 What: These files USE the colors defined in tailwind.config.js
   ⚠️  Don't add colors here - use Tailwind classes instead!

HOW TO CHANGE COLORS

Step 1: Open client/tailwind.config.js
Step 2: Find the colors object (line 11-22)
Step 3: Edit the hex code for the color you want to change
Step 4: Save the file
Step 5: Restart your dev server (npm run dev)
Step 6: All pages automatically update!

Example - Change primary blue from #0369a1 to #1e40af:
  BEFORE: primary: '#0369a1',
  AFTER:  primary: '#1e40af',

TAILWIND COLOR CLASSES USED IN PAGES

These are the actual Tailwind classes used throughout the app:

Buttons & Primary Actions:
  • bg-blue-600        (Medical Blue)
  • bg-teal-600        (Medical Teal)
  • bg-gradient-to-r from-blue-600 to-teal-600  (Gradient)

Text Colors:
  • text-blue-600      (Blue text)
  • text-teal-600      (Teal text)
  • text-green-500     (Success green)
  • text-red-600       (Error red)
  • text-gray-900      (Primary text)

Backgrounds:
  • bg-blue-50         (Light blue)
  • bg-teal-50         (Light teal)
  • bg-gradient-to-br from-blue-50 via-white to-teal-50  (Page BG)

Focus & Hover States:
  • focus:ring-blue-500
  • focus:ring-2
  • hover:bg-blue-700
  • hover:from-blue-700 hover:to-blue-800

TECHNICAL SPECIFICATIONS

Primary Colors:
  • Medical Blue: #0369a1 (RGB: 3, 105, 161)
  • Medical Teal: #0d9488 (RGB: 13, 148, 136)
  • Cyan Accent: #06b6d4 (RGB: 6, 182, 212)

Typography:
  • Font Family: Inter (Google Fonts)
  • Weights: 400, 500, 600, 700, 800
  • Sizes: h1(2.25rem), h2(1.875rem), h3(1.5rem)

Accessibility:
  • WCAG AA Compliant
  • Blue-600 on White: 9.2:1 contrast ratio
  • Teal-600 on White: 7.1:1 contrast ratio

Responsive Design:
  • Mobile-first approach
  • Tailwind breakpoints
  • All colors work on all screen sizes
